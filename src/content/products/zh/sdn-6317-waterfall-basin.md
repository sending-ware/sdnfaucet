## SDN-6317 瀑布面盆龙头

现代瀑布设计营造出宽大、优雅的水帘——为酒店浴室、豪华住宅项目和高端化妆台安装提供引人注目的视觉特征。

### 关键规格

| 参数 | 值 |
|---|---|
| 材质 | 不锈钢主体，黄铜阀芯外壳 |
| 表面处理 | 黑色、铬色、白色、拉丝金 |
| 出水类型 | 瀑布（宽流量） |
| 安装方式 | 单孔台装 |
| 阀芯 | 35mm 陶瓷盘 |
| 流量 | 1.5 GPM @ 60 PSI |
| 连接 | G1/2" 柔性软管 |
| 保修 | 3 年 |

### 特点

- **瀑布水流** — 宽大、层流的水帘提供像 SPA 一样的体验
- **多种表面处理** — 黑色、白色、铬色和拉丝金，可搭配任何浴室色调
- **冷热混水器** — 单手柄温度和流量控制
- **操作顺畅** — 陶瓷阀芯提供精确、无滴漏的控制
