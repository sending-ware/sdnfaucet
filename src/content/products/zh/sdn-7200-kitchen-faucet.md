## SDN-7200 系列厨房水龙头

我们的旗舰厨房水龙头系列，专为高流量商业和住宅厨房设计。具有磁性底座的抽拉式喷头确保每次都能顺畅缩回。

### 关键规格

| 参数 | 值 |
|---|---|
| 材质 | 304 不锈钢 / 黄铜主体 |
| 表面处理 | 铬色、拉丝镍、哑光黑 |
| 出水距离 | 220mm |
| 出水高度 | 380mm |
| 阀芯 | 40mm 陶瓷盘 |
| 流量 | 1.8 GPM @ 60 PSI |
| 连接 | G1/2" 标准 |
| 保修 | 阀芯 5 年，表面处理 2 年 |

### 特点

- **磁性底座系统** — 喷头每次都能牢固地卡回原位
- **双功能喷雾** — 在充气水流和强力喷雾之间切换
- **360° 旋转** — 全水槽覆盖，适用于多水槽设置
- **陶瓷阀芯** — 无滴漏性能，经过 500,000 次循环测试
- **易于安装** — 包含所有安装硬件及编织进水软管
